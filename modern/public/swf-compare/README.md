# Temporary SWF compare kit

One HTML page per SWF with **Ruffle** and **AwayFL** side by side.

Portfolio movies load from **`https://static.nikart.co.uk`** (CloudFront HTTPS + CORS). Child SWF/XML/JPEG URLs resolve from that movie directory, so this repo does not duplicate the bucket. The **legacy lizard Flash site** stays on `/fl/main.ruffle.swf` (same Ruffle tongue-chord patch as `/fl`) with Flash 8 flashVars and Ruffle `base=/fl/`. The compare page must not set `<base href="/fl/">` — that makes Safari resolve Ruffle WASM/workers under `/fl/` and abort the movie. Both players share one SWF fetch; AwayFL starts after Ruffle. AwayFL LoadVars still asks for `../content/json/data.json` against the HTML page; compare `players.js` rewrites that to `/content/`. A sibling file `/awayfl/loadvars-ondata-patch.js` makes the movie’s `LoadVars.onData` override stick (AwayFL marks that prototype slot read-only).

```bash
npm run swf-compare:html --prefix modern
```

That compiles `/swf-compare/index.html`, `/swf-compare/{id}/index.html`, `/swf-compare/{id}/fill.html`, and `visibility-defaults.json` from `pages.json`. Those outputs are gitignored. `postinstall`, `prebuild`, and `dev` run the same compiler, so a fresh checkout still has the pages. Edit `pages.json` (id, title, group, itemId, swf URL, stage width/height, base, legacy embed `background`, and `ruffle` / `awayfl` defaults). Optional fields: `loaderUrl`, `playerVersion`, `parameters`, `note`, and `stageBackground` (puts `data-background` on the compare stages; the fill page always uses `background`).

`/swf-compare/{id}/fill.html` is one player stretched into a box that fills the window while staying clipped to the SWF stage aspect ratio (`exactFit`), on a plain page whose background is that embed color. The compare page links to it. When both players default on, fill uses Ruffle; when both default off, it still uses Ruffle so the page opens. Index and piece links are root-absolute (`/swf-compare/…`) so they work from `/swf-compare` without a trailing slash; Next also redirects `/swf-compare` → `/swf-compare/index.html`.

`npm run swf-compare:sync --prefix modern` still reads wrapper HTML on the origin to discover SWF names. Fold anything new into `pages.json` and compile again. Ruffle and AwayFL runtimes are copied into `public/ruffle/` and `public/awayfl/` by `postinstall`/`prebuild` (gitignored). The LoadVars host patch stays in git at `public/awayfl/loadvars-ondata-patch.js`. Index cards (within each group) and piece topnav prev/next both follow `pages.json` order — not A–Z. Each piece page stores `{ ruffle, awayfl }` visibility in `localStorage` key `swf-compare-pages` (one entry per piece id), falling back to generated defaults in `visibility-defaults.json`. Hide/Show buttons sit next to each player, and index cards show those two flags as clickable toggles. Open `/swf-compare/index.html`. Portfolio launch buttons and `nikart.popWin` open `/swf-compare/{id}/fill.html`. The Banners item still opens the compare index, because that menu entry is several movies.
