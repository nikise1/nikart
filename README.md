# nikart

Portfolio site, in English and Spanish.

`www-root/` is the Next.js app. `legacy-2014/` is the 2014 Express app. Images and the portfolio JSON are shared from `content/`.

```bash
npm run www-root      # Next.js dev server
npm run legacy-2014   # 2014 site
```

Install, build, deploy, and content sync are in [`www-root/README.md`](www-root/README.md).
