# nikart

Portfolio site ([nikart.co.uk](https://www.nikart.co.uk)), in English and Spanish.

`www-root/` is the Next.js app that serves the site.

Media files are at [static.nikart.co.uk](https://static.nikart.co.uk).

Next.js, React, TypeScript, Tailwind CSS, GSAP, Zustand, next-intl.

From the repo root:

```bash
npm run www-root
```

Install, build, deploy, and content sync are in [`www-root/README.md`](www-root/README.md).

`legacy` has been migrated using an [AI-assisted plan](docs/legacy-migration/MIGRATION_PLAN.md).
